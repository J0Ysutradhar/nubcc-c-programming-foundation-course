# ১. কম্পিউটার কী? (What is a Computer?)

কম্পিউটার হলো একটি ইলেকট্রনিক ডিভাইস, যা ডেটা (Data) গ্রহণ করে, প্রক্রিয়াকরণ (Processing) করে এবং অর্থবহ তথ্যে (Information) রূপান্তর করে।

**উদাহরণ:** আমরা ক্যালকুলেটরে `10 + 20` ইনপুট দিলে কম্পিউটার হিসাব করে `30` আউটপুট দেয়।

### কম্পিউটার কীভাবে কাজ করে?

কম্পিউটার মূলত তিনটি ধাপে কাজ করে। একে **IPO Cycle** বলা হয়।

১. **Input (ইনপুট):** কম্পিউটারে ডেটা বা নির্দেশনা প্রদান করা।

২. **Process (প্রসেস):** ইনপুট দেওয়া ডেটার ওপর বিভিন্ন হিসাব বা কাজ সম্পন্ন করা।

৩. **Output (আউটপুট):** প্রসেসিং শেষে ফলাফল প্রদান করা।

**উদাহরণ:**

- Input: ১০ এবং ২০
- Process: দুটি সংখ্যার যোগফল নির্ণয়।
- Output: ৩০

---

# ২. প্রোগ্রামিং কী? (What is Programming?)

প্রোগ্রামিং হলো এমন একটি প্রক্রিয়া, যার মাধ্যমে নির্দিষ্ট প্রোগ্রামিং ভাষা ব্যবহার করে কম্পিউটারকে বিভিন্ন কাজ সম্পন্ন করার জন্য নির্দেশনা (Instruction) দেওয়া হয়।

সহজ ভাষায়, কম্পিউটারকে কী করতে হবে এবং কীভাবে করতে হবে, তা নির্দেশ দেওয়ার প্রক্রিয়াই হলো প্রোগ্রামিং।

**উদাহরণ:** আমরা যদি কম্পিউটারকে দুটি সংখ্যা যোগ করতে বলি, তাহলে প্রোগ্রামিংয়ের মাধ্যমে তাকে সেই নির্দেশনা দিতে পারি।

# ৩. প্রোগ্রামিং ল্যাঙ্গুয়েজ কী? (What is a Programming Language?)

Programming অর্থ নির্দেশনা দেওয়ার প্রক্রিয়া এবং Language অর্থ ভাষা।

প্রোগ্রামিং ল্যাঙ্গুয়েজ হলো এমন একটি নির্দিষ্ট ভাষা বা নিয়মের সমষ্টি, যার মাধ্যমে মানুষ কম্পিউটারকে বিভিন্ন নির্দেশনা দিতে পারে।

**উদাহরণ:** C, C++, Java, Python, JavaScript ইত্যাদি।

প্রতিটি প্রোগ্রামিং ল্যাঙ্গুয়েজের নিজস্ব Syntax (লেখার নিয়ম) রয়েছে।

# ৪. C Programming Language-এর ইতিহাস

- C Programming Language তৈরি করেন **Dennis Ritchie**।
- এটি ১৯৭২ সালে যুক্তরাষ্ট্রের Bell Laboratories-এ তৈরি করা হয়।
- UNIX Operating System তৈরিতে C গুরুত্বপূর্ণ ভূমিকা পালন করে।
- C ভাষার আগে B Programming Language ছিল, যা থেকে C-এর বিকাশ ঘটে।

### C-কে Programming Language-এর জননী বলা হয় কেন?

C-কে অনেক সময় Mother of Programming Languages বলা হয়। কারণ, পরবর্তীতে তৈরি হওয়া অনেক জনপ্রিয় প্রোগ্রামিং ভাষার গঠন ও ধারণায় C-এর প্রভাব রয়েছে।

বিশেষ করে C++ এবং অন্যান্য অনেক ভাষা C-এর Syntax ও বিভিন্ন ধারণা দ্বারা প্রভাবিত।

---

# ৫. C Language-এর বৈশিষ্ট্য (Features of C)

**১. Middle-Level Language:** C-কে সাধারণত Middle-Level Language বলা হয়। কারণ এতে High-Level Language-এর সুবিধা এবং Low-Level Programming-এর কাছাকাছি কাজ করার ক্ষমতা রয়েছে।

**২. Compiled Language:** C প্রোগ্রাম চালানোর আগে সাধারণত Compiler দিয়ে Compile করতে হয়।

**৩. Fast Execution:** C প্রোগ্রাম সাধারণত দ্রুত কাজ করতে পারে।

**৪. Structured Programming:** C-তে প্রোগ্রামকে ছোট ছোট Function-এ ভাগ করে সাজানো যায়।

**৫. Portable:** প্রয়োজনীয় পরিবর্তনসহ বিভিন্ন Operating System-এ C প্রোগ্রাম চালানো যায়।

---

# ৬. C Programming কোথায় ব্যবহার করা হয়?

C Programming বিভিন্ন গুরুত্বপূর্ণ ক্ষেত্রে ব্যবহার করা হয়।

১. **Operating System:** Operating System-এর বিভিন্ন অংশ তৈরিতে। যেমন Linux Kernel।

২. **Embedded Systems:** বিভিন্ন ইলেকট্রনিক ডিভাইস ও মাইক্রোকন্ট্রোলারে।

৩. **Device Drivers:** Hardware এবং Operating System-এর মধ্যে যোগাযোগ স্থাপনে।

৪. **Compiler Development:** বিভিন্ন Programming Language-এর Compiler তৈরিতে।

৫. **Database Systems:** Database Software-এর বিভিন্ন অংশ তৈরিতে।

৬. **System Software:** বিভিন্ন System-Level Software তৈরিতে।

---

# ৭. C Programming কীভাবে কাজ করে?

C একটি Compiled Programming Language। অর্থাৎ C প্রোগ্রাম চালানোর আগে Source Code-কে Compile করতে হয়।

C Programming-এর সাধারণ কাজের ধাপগুলো হলো:

**Step 1: Write Source Code**

প্রথমে Programmer একটি C প্রোগ্রাম লিখবে।

C Programming ফাইলের Extension হলো `.c`।

উদাহরণ: `main.c`

**Step 2: Compilation**

এরপর Compiler Source Code-কে Machine Code-এ রূপান্তর করার প্রক্রিয়া সম্পন্ন করে।

**Step 3: Executable File**

Compilation এবং Linking সফল হলে একটি Executable File তৈরি হয়। Windows-এ সাধারণত এর Extension হয় `.exe`।

**Step 4: Execution**

এবার Executable File রান করলে কম্পিউটার প্রোগ্রামটি Execute করে এবং Output দেখায়।

### সম্পূর্ণ প্রক্রিয়া:

Source Code → Compiler → Executable File → Execution → Output

---

# ৮. Compiler কী? (What is a Compiler?)

Compiler হলো একটি বিশেষ ধরনের System Software, যা Programming Language-এ লেখা Source Code-কে কম্পিউটারের জন্য Machine Code বা উপযোগী নিম্নস্তরের কোডে রূপান্তর করে।

সহজ ভাষায়, Compiler মানুষের লেখা প্রোগ্রামকে কম্পিউটারের বোঝার উপযোগী কোডে রূপান্তর করতে সাহায্য করে।

**Machine Code:** কম্পিউটারের প্রসেসর সরাসরি যে Binary Instruction (0 এবং 1) কার্যকর করে, তাকে Machine Code বলা হয়।

### GCC কী?

GCC-এর পূর্ণরূপ হলো **GNU Compiler Collection**।

এটি একটি জনপ্রিয় Compiler Collection, যা C, C++ সহ বিভিন্ন Programming Language-এর কোড Compile করতে পারে।

C-এর জন্য GCC এবং C++-এর জন্য G++ Compiler ব্যবহার করা যায়।

---

# ৯. C Programming-এর জন্য কী কী প্রয়োজন?

C Programming শুরু করতে সাধারণত নিচের বিষয়গুলো প্রয়োজন:

১. **Code Editor / IDE:** যেখানে Programmer কোড লিখবে। যেমন Visual Studio Code (VS Code)।

২. **Compiler:** যে Source Code Compile করবে। যেমন GCC।

৩. **Terminal:** যেখানে Compile এবং Run করার Command দেওয়া হয়।

৪. **Debugger:** প্রোগ্রামের ভুল খুঁজে বের করতে এবং ধাপে ধাপে প্রোগ্রাম পরীক্ষা করতে সাহায্য করে। যেমন GDB।

### Windows-এ প্রয়োজনীয় Setup

- Visual Studio Code (VS Code)
- MSYS2
- MinGW-w64 (GCC Toolchain)
- VS Code C/C++ Extension

**মনে রাখবে:** VS Code একটি Code Editor, Compiler নয়। তাই শুধু VS Code ইনস্টল করলেই C Program সরাসরি Run করা যায় না। এর জন্য আলাদা Compiler ইনস্টল করতে হয়।

# ১০. আমাদের প্রথম C Program

চলো, একটি সাধারণ C Program দেখি।

```c
#include <stdio.h>

int main()
{
    printf("Hello Northern University!");

    return 0;
}
```

**Output:**

```text
Hello Northern University!
```

এই প্রোগ্রামটি রান করলে স্ক্রিনে `Hello Northern University!` লেখাটি দেখা যাবে।

### প্রোগ্রামের বিভিন্ন অংশের পরিচয়

| Code | কাজ |
|---|---|
| `#include <stdio.h>` | Standard Input Output Header File যুক্ত করে। |
| `int main()` | প্রোগ্রামের Main Function। |
| `{ }` | Function-এর Body নির্দেশ করে। |
| `printf()` | স্ক্রিনে Output প্রদর্শন করে। |
| `return 0;` | প্রোগ্রাম সফলভাবে শেষ হয়েছে তা নির্দেশ করে। |
| `;` | Statement-এর সমাপ্তি নির্দেশ করে। |

**বিশেষ দ্রষ্টব্য:** এই অংশগুলো সম্পর্কে বিস্তারিত আমরা পরবর্তী ক্লাসগুলোতে শিখব।
